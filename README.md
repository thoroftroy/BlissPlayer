# BlissPlayer

A small offline music player with a Windows XP look, in light blue and dark XP night themes.

It plays the music on your phone, keeps every song at the same volume, and can push quiet outputs as high as 500 percent without harsh clipping.

## Features

- Library grouped by Songs, Artists, Albums, plus Playlists
- Play all music, Shuffle, Loop Off, Loop All, Loop One
- Smart Shuffle that favors songs played less, so the mix stays fresh
- Queue that always shows the true play order: tap to jump, swipe to remove, drag to reorder
- Play next always lands right after the current song
- One tap loudness matching across the whole library, safe and undoable
- Master Boost from 1 to 500 percent, with named presets and per output memory
- Edit song details and delete songs from inside the app
- Notification, lockscreen, headset, and Bluetooth controls with a live position bar
- Optional volume guard that puts the level back when the phone lowers it on its own

## Install

Copy `BlissPlayer-v0.6-debug.apk` to the Android phone and tap it (allow install from unknown sources when asked). Open the app, grant the music permission, tap Scan for music, then Play all music.
