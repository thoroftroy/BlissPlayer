# BlissPlayer

A small music player with a Windows XP look, in light blue and dark XP night themes.

It plays the music on your phone, keeps every song at the same volume, and can push quiet outputs much louder when the phone alone is not enough.

## Features

- Library grouped by Songs, Artists, Albums, Genres, and Playlists
- Contextual Play button, Loop Off, Loop All, Loop One
- Smart Shuffle that favors songs played less, with adjustable strength or plain random
- Queue that always shows the true play order: tap to jump, swipe to remove, drag to reorder
- Play next always lands right after the current song
- One tap loudness matching across the whole library, safe and undoable
- Master Boost up to 2000 percent with a type-in box, named presets, and per output memory
- Skip parts of songs automatically with per-song segments
- Edit song details and delete songs from inside the app
- Notification, lockscreen, headset, and Bluetooth controls with a live position bar

## Install

Copy `BlissPlayer-v0.7.8-debug.apk` to the Android phone and tap it (allow install from unknown sources when asked). Open the app, grant the music permission, tap Scan for music, then Play.
