# BlissPlayer

A music player with an Explorer-style library, classic control panels and a retro playback deck, in light and dark XP themes.

It plays the music on your phone, keeps every song at the same volume, and can push quiet outputs much louder when the phone alone is not enough.

## Features

- Library grouped by Songs, Artists, Albums, Genres, and Playlists
- Contextual Play button, Loop Off, Loop All, Loop One
- Smart Shuffle that favors songs played less, with adjustable strength or plain random
- Queue that always shows the true play order: tap to jump, swipe to remove, drag to reorder
- Play next always lands right after the current song
- One tap loudness matching across the whole library, safe and undoable
- Master Boost up to 2000 percent with a type-in box, named presets, and per output memory
- Automatic output presets, including Bluetooth disconnect fallback
- Live bass, midrange, treble and preamp controls with optional headroom
- Song-name cleanup and metadata review, with Android write-access prompts
- Skip parts of songs automatically with per-song segments
- Edit song details and delete songs from inside the app
- Notification, lockscreen, headset, and Bluetooth controls with a live position bar

## Install

Copy the newest `BlissPlayer-v0.8.x-debug.apk` to the Android phone and tap it (allow install from unknown sources when asked). Open the app, grant the music permission, then Play. Accept the background-play settings prompt for screen-off playback, or change it later in More.

The frequency mixer is in More, Live sound mixer. It starts bypassed; supported bands and their ranges depend on the audio output. Positive gain can distort or harm hearing and speakers. Start low.

Crash reports stay private in the app and are offered once. More lets you copy the last report or export it to a file you choose.
